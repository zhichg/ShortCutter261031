# ShortCutter261031

Windows 鼠标手势、全局热键和应用启动器，使用 C 与 Win32 API 实现。2026-10-31 发布版本。

从 [Releases](https://github.com/zhichg/ShortCutter261031/releases/latest) 下载 Windows 便携包，解压后运行 `ShortCutter.exe`。首次启动自动创建配置；升级时先退出托盘中的旧实例。

## 日常使用

- 从托盘、手势或热键打开 Dashboard。输入命令名称，上下选择，Tab 补全，回车或空格执行。
- Dashboard 打开或再次唤起时置顶并聚焦搜索框；点击窗口外会关闭，重新打开后可立即输入，空搜索时回车或空格执行历史命令。
- 按住 Ctrl 点选多个命令，松开后按选中顺序执行；重复点选移出队列，Esc 取消。
- F6 切换搜索框和快捷方式网格。网格支持方向键、回车，以及 Ctrl+回车加入队列。
- 快捷方式可拖动排列、分组为文件夹、分页；小屏幕保持图标尺寸并提供滚动，也可选择紧凑布局。
- 搜索继续禁用输入法。A–Z 键在各输入法与键盘布局下直接输入英文字母；支持选区、复制、剪切、粘贴和撤销。粘贴接受英文字母和数字。

## 设置

设置分为常规、仪表盘、命令、手势和热键五页。窗口可调整大小，列表支持搜索、命令列排序、完整目标详情和来源标记。

修改先保留为草稿，点击“保存并应用”后生效；取消或关闭会放弃未应用的修改。中英文切换先在设置中预览。保存失败会保留草稿并提示原因，不显示保存成功。

设置窗口会自动记住正常状态下的宽高，拖动结束或关闭窗口时保存；取消设置修改也会保留窗口大小。下次打开及重启程序后按当前缩放比例恢复，并限制在屏幕工作区内。最大化、最小化不覆盖正常尺寸。

命令、手势和热键列表分别记住调整后的列宽，拖动后自动保存；关闭、切换语言和重新启动后保留，并随屏幕缩放比例恢复。列宽和窗口大小独立于尚未应用的设置草稿。

“仪表盘 → 快捷输入”提供总开关、桌面和资源管理器两个范围选项。只有 A–Z 键可触发；Ctrl、Alt、Win 组合键、活动输入框、重命名、菜单、鼠标捕获和拖动保留原有操作。其他应用暂不启用快捷输入。

“常规”设置语言、开机启动、启用/暂停快捷键、触发鼠标键、手势尺寸、识别阈值和轨迹外观。识别阈值范围为 50–95%。左右 Win 修饰键都可使用。

## 命令与扫描

运行命令可以设置目标、参数、工作目录、激活已运行窗口、执行前确认和管理员权限。激活选项仅用于可执行程序，按完整进程路径匹配；文档、目录、网址和快捷方式始终交给 Windows 正常打开。成功执行后才记录使用次数，失败会提示并写日志。

扫描应用在后台读取桌面和开始菜单快捷方式。导入保留 `.lnk` 本身，因此原有参数、工作目录和同一应用的不同启动入口仍然有效。筛选不会清除勾选状态；容量不足时会要求减少选中项。

命令、手势和热键各支持 100 项，Dashboard 支持 256 个条目和 32 页。编辑按稳定命令 ID 查找对象；删除自定义命令会清理或停用关联的热键、手势和快捷方式引用，旧 ID 不会被新命令复用。

## 手势与按键序列

在手势录制画布上按住右键绘制，最多三个采样，随后选择修饰键、屏幕区域和命令。方向链以箭头显示；捕获取消或暂停会清除未完成的轨迹。屏幕分区使用虚拟桌面坐标，支持位于主屏左方或上方的显示器。

手势按起笔位置确定区域。主区域及四角手势只在各自区域触发；选择“全部区域”后可在任意区域触发。区域专用手势与全部区域手势相似度相同时，优先触发区域专用手势。

按键命令通过录制创建：在“命令 → 新建”选择“按键”，点击“开始录制”，按下所需的组合键或连续按键，最后用鼠标点击“停止录制”。预览只读，以 ↓ / ↑ 显示按下和松开，同时显示按键间隔；无需输入按键代码。

重新录制会替换当前序列；未录入任何按键就停止会保留原序列。“清空”移除当前序列，清空后需重新录制才能保存。录制期间 Tab、Enter、Esc 和 Ctrl/Alt/Win 组合键会被捕获；切换到其他窗口时自动停止。停止时补齐尚未松开的按键，避免保存不完整的序列。开始录制前已按住的按键需先松开再重新按下。

录制保留左右修饰键、小键盘、扩展键和按键间隔，忽略长按产生的重复按下事件。累计间隔最多 60 秒；达到时长或存储上限会自动停止并保留已录入内容。内置按键命令保持只读。

已有配置中的按键序列继续兼容，例如：

```text
{Ctrl down}{C}{Ctrl up}{Sleep 100}{Ctrl down}{V}{Ctrl up}
```

原有 `{按键}`、`{按键 down}`、`{按键 up}` 和 `{Sleep 毫秒}` 配置仍有效；录制使用保留虚拟键码及扩展键标志的标记存储。保存前检查未知按键、未闭合的标记和不配对的按下/释放。延迟由计时器调度，避免阻塞输入处理。取消或执行失败会释放程序模拟按下的修饰键；物理按住的按键仍由用户控制。

## 脚本

`scripts\` 中的 `.bat`、`.cmd`、`.ps1` 和 `.vbs` 在启动及打开设置时同步为命令。文件名以 `_Show` 结尾时显示脚本窗口，其余默认隐藏。程序不再在启动时生成或覆盖 README 与脚本指南。

在设置中改名程序自身 `scripts\` 目录内的脚本时，实际文件改名延迟到“保存并应用”；保存失败会回退。外部目录脚本仅修改显示名称。名称必须是有效文件名，不允许目录分隔符和保留设备名。

## 保存、权限与日志

- 配置文件是程序同目录的 `ShortCutter.ini`，采用 UTF-16 LE INI；文本字段从 UTF-8 转换并转义，支持中文、多行和引号。旧版未转义配置仍可读取。
- 保存先写同目录临时文件，检查写入和刷新结果，再替换原文件；最近一次成功配置保存在 `.bak`。失败不会截断原配置。
- 普通启动使用当前用户权限。只有单条命令明确勾选管理员选项时，才申请提升权限。
- 开机启动只在用户应用不同的开关值时更新当前用户启动项，并兼容清理旧计划任务。若旧任务由管理员创建，清理时会申请一次 Windows 管理员权限确认；仅清理工具提升权限，取消确认会保留原设置与修改草稿。清理完成后再次切换自启无需提升权限。启动程序及保存其他设置不会重复更新启动项。
- `ShortCutter.log` 位于程序目录，达到 1 MB 后保留上一份日志。托盘显示实际启用和监听状态；任务栏重建后恢复图标。

## 构建

需要 MinGW-w64 的 GCC 与 windres。工具在 PATH 中时运行 `build.bat`；也可以在当前命令窗口设置 `MINGW` 指向工具链根目录。脚本只更改当前进程环境。

```bat
set "MINGW=D:\path\to\mingw64"
build.bat
```

主要模块：`config.c` 负责数据及持久化，`actions.c` 负责动作队列，`gesture.c`/`quick_input.c` 负责输入，`dashboard.c` 负责仪表盘，`ui.c` 及 `ui_apply.h`/`ui_scan.h`/`ui_help.h` 负责设置、应用事务、扫描和帮助。

## 验证

`tests\run-key-record.ps1` 编译并运行按键录制测试，覆盖组合键、左右修饰键、小键盘及扩展标志、旧格式兼容、长间隔、时间戳回绕和容量边界，以及实际编辑窗口的只读预览、启停状态、保存重开、取消、失焦停止和内置命令保护。窗口测试使用模拟的录制钩子，不执行按键注入，不读写用户配置，也不启动正式程序。构建工具要求与 `build.bat` 相同。

本轮真实系统上的全局钩子、管理员目标窗口、开机启动、资源管理器重启、多显示器热插拔及屏幕阅读器兼容性仍需实际使用验证；隔离测试不替代这些检查。

## 本版更新

- 按键命令支持录制、停止和只读预览，兼容旧序列。
- 设置标签切换完整重绘，清理旧页面残影。

## 发布内容

仓库包含源码、图标原图、构建脚本、维护中的测试，以及离线拼音数据和上游许可证。`scripts/` 提供构建工具、脚本指南及通用示例；运行时脚本会自动成为命令。

个人配置、日志、本机路径脚本、调试备份和旧版本目录未包含在发布中。发布包使用默认配置，运行时不需要 Python；只有重新生成图标需要 Python 和 Pillow。离线拼音数据来源见 `third_party/README.md`。
